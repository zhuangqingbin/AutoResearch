## 生产契约

- 主尺固定 `gap_c1_o2`：D1 收盘入场、D2 开盘退出。实际超窗另记，不补理想成交。
- `skills-gap-v3` 冻结于 run；旧 v2 保持旧语义。FULL/LITE 是研究深度。
- `research-decision-v2` 提供统一卡片字段，`conditional-scenarios-v1` 声明收益分母。
- `decision-claim-uses-v1` 只声明用途；核验结果由根确定性层生成。来源未知不等同证伪，PASS 不升级评级。
- 只允许同票、同 run、有效 attempt 的证据进入本票事实。相同网址、同来源、相同字节及更正链不构成独立替代。
- 已拒稿/裁剪断言仍保留人口；证据人口无法可靠持久化时阻止卡片通过，不计为零断言。
- `dossier-facts-v1` 分 STABLE、DYNAMIC、HYPOTHESIS；未知旧叙述不自动变成可复用事实。

1. 取消确认：暂态进程组探测错误不误判成功；有界重查、TERM/KILL 升级和未知状态仍保留。

3. D1：决策前冻结结束后再次核对截止；标签人口与冻结选择完全对账；独立初判与不同运行绑定；导出只读 canonical 字节。
4. C6：独立信任公钥、原生调用/结果与 hook 同 call ID 核对；拒绝篡改、路径跳转、旧策略指纹及历史证明冒充当前加载。
5. D3：冲突 claim 先合并再判定；公开/可得时间与实际 receipt 对账并保留精度。
6. D4：已发布档案维护有独立操作证据链与持锁 CAS；动态事实的新鲜度来自源，旧数字不能仅改日期或类别复活，失败 attempt 不能支持复用。发布在同一目标锁内核对可见 opening 与底层 publication base，阻止首次或恢复发布覆盖期间新增的维护；已提交重入保持幂等。
