# 家族 × 尺 · edge 普查（2026-08-22）

## 0. 假设与判读规则（先写后看；本节 commit 早于任何读数）

**问题**：在现行决策尺 `gap_c1_o2`（T+1 收盘买 → T+2 开盘卖，2026-07-10 / 08-05 用户裁定）下，漏斗各层产出的**每一个家族**——L1 各路召回集、L2 菜单与各桶、L3 finalist/bench/lane/conviction 档、L4 五档评级/早停/三门、E6 rank1/eligible/硬否决——相对全市场可交易截面，有没有任何一个量得出正超额？

**为什么现在问**：08-07 两尺对照报告已证 value 路王座作废（+1.04% → −0.07%）、L3 真选 edge 归零（+0.93% → −0.06%）、门的价值配对 −0.68%（n=6）；08-21 Gate 0 证 lowturn −0.24pp、healthy −0.17pp。记忆里「门价值 +4.35pp / 评级 rank-IC +0.55」全是旧尺 `fwd_2_oc` 读数，换尺后**从未重建**。本普查把所有家族放进同一张表、同一把尺、同一个基准，一次看完。

- **H0**：没有任何家族满足「正证据」判据（下）。
- **H1**：至少一个家族满足。本普查**不裁决任何产品/流程变更**，只给裁决者看读数。

**判读规则**（逐家族 × 主尺；对 `fwd_5_oc` / `fwd_10_oc` 只观察，不判读）：
- **正证据**：相对超额均值 > 0 **∧** 配对 t ≥ **2.0** **∧** n_days ≥ **20**；
- **显著负**：相对超额均值 < 0 ∧ t ≤ −2.0 ∧ n_days ≥ 20；
- **未证**：其余（**不显著 ≠ 有 alpha**）；
- **样本不足**：n_days < 20（只印数，不判）。
- 不设停机——普查不是门。

**口径**（与幸存仪器 `lowturn_precheck` 对齐，差异处显式标注）：
- 价格 = `lake/daily/*.parquet`（生产湖，零网络）；前向收益复用 `research.factor_lab.forward_returns`（`gap_c1_o2` / `buyable_c1` / `fwd_5_oc` / `fwd_10_oc` 同一实现）。
- 市场基准人口 = 当日**全湖**可交易票（`ruler.entry_tradable` 折叠，**不设市值地板**）—— 与 E6 `rel_gap_market`「全市场可交易等权、含漏在 L0 的票」同一人口；与 `lowturn_precheck`（研究面板，cap_floor 30 亿）不同，差异显式。
- 相对超额 = 家族内均值 − 当日截面**中位**（主列，同 `lowturn_precheck`）；另给 − 截面**等权均值**（E6 口径）一列。配对 t = 逐日超额的 one-sample t。
- 家族成员 = 每个扫描日 staging 产物（`context_claude/scan/<date>/`）；产物缺席 → 该家族该日不计，**不伪造为空集**；各家族 n_days 各自报。
- **📌 保送票从 L3/L4/E6 所有家族剔除**，单列一族（2026-07-16 判例：保送不是排序的产物）。
- 评级 rank-IC = 逐日 Spearman(评级序数 Buy5…Sell1, gap)，≥5 张卡且 ≥2 档才算；跨日均值 + t。
- 可算日 = D+2 有收盘数据的扫描日；`|gap| > 31%`（板极值+容差）视作数据错剔除并计数。

**不做**：不回注、不记账、不改任何生产代码、不动主尺、不分 regime（样本薄，加了只会诱导调参）。
