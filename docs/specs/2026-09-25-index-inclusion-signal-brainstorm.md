## 1. 前提检查:隔夜主尺上「纳入 = 利好」成立吗

### 1.1 普查口径(抛弃型)

- 事件:沪深300 / 中证500 / 中证1000 / 中证A500 / 创业板指 的半年调样(2022-06 → 2026-06,9 次)+ 科创50 季度调样(16 次);生效日 E = 6/12(科创50 另 3/9)月第二个周五收盘后,公告日 A = E − 14 天周五盘后(已对 2022–2026 逐次核对规则成立)。
- 调入/调出 = tushare `index_weight` 月末快照相邻月之差(本 token 有权限,2005 年起);收益 = `lake/daily`(2022-03 起,湖无缺日);ETF 规模 = `fund_basic`(基准含指数名)× `fund_share` × `fund_nav`(均有权限)。
- 基准两套:全 A 等权 / **同指数未变动成分股**(消掉大小盘错配)。下表用后者。t_day 按(调样, 指数)格子聚合。

### 1.2 调入票读数(5 个半年调样指数,n=1652 票次,超额单位 pp)

| 扫描日 D | 这一夜买的是什么 | 超额 | 胜率 | t_obs | t_day |
|---|---|---|---|---|---|
| A−2 | 公告前两夜 | −0.18 | 47% | −2.9 | −2.0 |
| **A−1** | **预测夜:买 A 收 → 卖 A+1 开(公告在 A 盘后落地)** | **+0.21** | 57% | 5.1 | **3.2** |
| A | 公告夜追买 | −0.07 | 50% | −1.5 | −0.9 |
| A+1..E−3 | 生效前跑道(两周) | −0.10 | 49% | −5.6 | **−5.4** |
| E−2 | 买 E−1 收 → 卖 E 开 | −0.04 | 44% | −0.9 | −0.2 |
| **E−1** | **买 E 收(被动资金买入的那个收盘)→ 卖 E+1 开** | **−0.31** | 35% | −8.2 | −2.3 |
| E | 买 E+1 收 → 卖 E+2 开 | −0.05 | 49% | −1.4 | −0.6 |
| E+1..E+3 | 生效后 | −0.07 | 49% | −2.6 | −2.4 |

分指数:
- A−1 正证据集中在 **沪深300 +0.74(胜 75%,t_day 2.6)、中证A500 +0.63(胜 73%,t_day 2.6)、科创50 +1.03(胜 79%,t_day 3.9,n=47)**;中证500 +0.10 / 中证1000 +0.16 / 创业板指 0.00 无边。
- E−1 负证据集中在 **中证500 −0.72(胜 22%,t_day −5.6)、中证1000 −0.25(t_day −2.7)**;沪深300 +0.15 / A500 +0.05 / 科创50 +0.31 均不显著。
- 科创50 公告夜 −0.43(t_day −2.2):小指数公告后追买直接为负。
- 调出票:各相位 −0.13 ~ +0.01,没有可用结构(E−1 也是 −0.13)。
- 被动流是真的:生效日成交额 / 前 20 日均 = **调入票 1.86× vs 未变动股 1.1×**。ETF 规模(仅 ETF,不含增强/保险/雪球对冲)沪深300 ≈3031 亿、A500 ≈2040 亿、科创50 ≈1737 亿、创业板指 ≈958 亿、中证1000 ≈411 亿、中证500 ≈80 亿;沪深300 2026-06 调入票的 ETF 被动买入 ≈ **0.1–0.5 天 ADV**。
- 流量强度三分组(权重/ADV 粗代理)对 E−1 负值不分层(−0.28/−0.29/−0.33):反转不是流量比例的,是「调样收盘」这件事本身。

### 1.3 读法与警告

1. **用户常识里的利好相位(公告后持有到生效)在隔夜尺上是零或负**,与 `STAGES.md:363` 对业绩预告的否决同族:「公告后追买无肉;alpha 若有,在披露前的预期变化里」。
2. **唯一正相位需要在公告前一天就知道名单**(A−1 夜)。沪深300/A500/科创50 的 +0.6~+1.0pp、胜率 73–79% 是本项目迄今量到的最强正证据(此前唯一正证据是 composite +0.14 半样本),但它每年只出现 2–4 个交易夜,且上表是**完美预见**(用真实调入名单),真实可得收益 = 预测精度 × 上表 + (1−精度)× 误报票收益。
3. **生效前夜(E−1)恰好是本系统「买 T+1 收盘」会撞上的相位**:扫描日 E−1 → 买 E 收盘 = 和被动资金一起在同一个收盘价买入 → 次日开盘回吐。中证500 调入票胜率 22% 是普查里最干净的负结构。
4. 有效性前提:n=17 次调样、2022–2026 单一大周期、未扣成本、月末快照含临时调整(如 2026-09-09 中金吸收合并东兴/信达引起的样本临时调整)污染。

## 2. 事件时间结构 × 本系统结构

```
       A−1          A(盘后公告)     A+1 … E−3        E−1          E(收盘生效)     E+1…
扫描日  ↑预测夜(+)     ↑追买(0)        ↑跑道(−)         ↑撞被动收盘(−−)  ↑(0)
数据    只有预测名单    公告 xlsx 名单可机读 ————————————————→  index_weight 月末快照(事后)
```

本系统能拿到的三种「名单」:
- **预测名单**(A−1 之前):中证编制规则是公开的(过去一年日均成交额剔后 50% → 日均总市值排名 → 缓冲区 240/360),`lake/daily` + `lake/daily_basic` 有一整年数据即可确定性复现;券商预测名单通常在公告前 2–4 周见报。
- **公告名单**(A 盘后起):中证公告 API 机读已验证——`announcement/queryAnnouncementByType`(列表,含 `indexrebalancingAnnouncements` 数组)→ `announcement/queryAnnouncementById?id=`(正文 + `enclosureList`)→ `oss-ch.csindex.com.cn/notice/*.xlsx`(**每指数一行:指数代码/简称 · 调出(代码,简称)×2 · 调入(代码,简称)×2**,2026-09-09 临时调整附件 166 行实测解析成功)。列表接口不分页(只给最新 5 条),历史需靡靠规则或自建湖累积。
- **事后名单**(月末):tushare `index_weight`,做普查与回填。

## 4. 三条路线

### 路线 A「正向催化加分」—— 否决

把「即将纳入」作为利好喂 L3 列 / L4 简报 / E6 面。普查:公告夜 −0.07、跑道段 −0.10(t_day −5.4)、生效前夜 −0.31。**在隔夜尺上加分就是加错方向**;同时是比行业席位更强的方向性锚(防锚定约束)。不做。

### 路线 B「日历事实 + 生效前夜守卫」—— 推荐,批 4 之后实施

零 LLM,全确定性,一年真正起作用 ≈4 个交易日,其余日子逐字 parity。

- **B1 数据**:新 source adapter `csindex`(列表 → 详情 → xlsx 解析,B 级契约,`persist_violations=False` 类脆源);tushare `index_weight`(key=period,月末,用于普查/回填/校验)、`fund_basic/fund_share/fund_nav`(ETF 规模,描述字段用);全部登记 endpoints + contracts;湖 `lake/index_changes/`。
- **B2 事件表 `index_events.csv`**(先进 ARTIFACTS):`code, index_code, index_name, side(add|drop), ann_date, eff_date(被动调仓收盘日 E), phase(announced_runup|passive_close_eve|post), est_flow_yi, flow_adv_days, source(csindex|rule)`。**跨指数净额**(沪深300 调出多半是中证500 调入,同一票两行要能净)。**缺席 ≠ 否**:源不可达 → 文件缺席 + run_health 降级行;源可达无事件 → 只有表头的空表。
- **B3 日历第三腿**:`calendar.py` 加 `kind="index_rebalance"`,文案是事实不是方向:「📅 指数调样:沪深300 调入,06-12 收盘生效(ETF 被动买入 ≈0.3 天 ADV)」;`calendar_flags` 使 L4 简报 / summary 📅 未来 14 天 / sector pack / 档案 §6 同时继承。
- **B4 守卫**:E6 新硬门 `rebalance_close`:仅当扫描日 D = E−1 且候选在当日事件表(add 或 drop)时 fail,独立计数;旋钮 `relative_buy.rebalance_gate {enabled, indices}` 三件套,一行回滚。范围待裁(E2):全部调样票(简单可解释,300/A500 那夜 ≈0 不亏)vs 只中证500/1000(证据所在)。L4 侧:两引擎 agent def 在 P3 读到日历行「生效前夜」时,入场行写 `禁止`(理由词用现有 `其他`,不改 7 词早停契约);E6 门是确定性兜底,不依赖 LLM 听话。
- **B5 stock-research**:`blocks_ashare` 的 WebSearch 兜底换成确定性一行(有事件写事实,无事件写「近 60 日无调样事件(源可达)」);美股不动(us-intel 面已有)。
- **B6 观察义务**:run_health/buyability 记 `rebalance_gate_hits`(分指数);每次调样后读被拦票的实现 gap;守卫命中数 0 的日子必须能分辨「没到日子」和「门坏了」(`gate_evaluated: true/false`)。
- 测试:删掉门 → 至少一个测试变红(09-24 变异测试教训);两引擎 agent def 锚测试同步。

### 路线 C「预测名单席位」—— spike 先行,读数达标再设计

- 确定性复现中证编制规则(先只做沪深300,再 A500/科创50),产出 `predicted_index_adds.csv`(先登记);**只在 D = A−1 那一天**(日历知道 A)把预测调入票作保留席位注入 L1(镜像 `sector_seats`),L3 见 🗓 列 + 图例三条对冲(预测名单 · 不因席位抬评级 · B 条照常),L4 正常研究,E6 同一规则下比较(裁定⑥:通道不自产 BUY)。其它日子零改动。
- **spike 判据(离线,冻结窗内可做)**:在 2023-06 → 2026-06 的 7 次半年调样上回测预测器:精度/召回;**预测集(含误报)的 A−1 夜实现超额 ≥ +0.4pp 且胜率 ≥ 65%** 才立项;否则记负结果不做。
- 诚实预期:每年 2–4 夜、每夜 ≤1 只 BUY,绝对贡献很小;价值在于它是「成功日 ≥1 BUY」在那几天的天然来源,且是目前唯一量到的正相位。
