# 全扫计量与恢复优化

用户已确认 2026-10-09 的降本方案，本次在现有工作树实现。

## 设计边界

计量按实际 transcript 覆盖范围去重，保留任务、attempt 与领域拒绝记录。未知模型价格继续未知，订阅额度不换算为 API 美元。卡片修订可复用同日、输入哈希一致、已接受且仍有效的情报，但重新运行情报守卫；缺少任一证明则重新研究。

额度耗尽是容量暂停，停止新的推理派发，收完已在飞任务，保留 ACTIVE run 和已接受产物。暂停不是评级失败，也不消耗 L4 票据重试。恢复命令只给确切失败 attempt 一次新的派发授权，保留原失败证据，并再次校验冻结输入。不会更改历史 FAILED run。组装失败同样可在修复代码后单独授权恢复，发布继续走现有事务与 verify-report。

生产模型、三门、覆盖率、复核条件、C4 绑定顺序均保持。小上下文和低 effort 只生成隔离、冻结的实验配置；真实宿主边界与质量等价验证之前不进入生产。
