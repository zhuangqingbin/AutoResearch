## 1. 总纲:六问的答案先看第⑥问——链路不一致的三个真病灶

**先纠正问题本身:"每天几乎没有 buy"不等于链路坏了。** 账本证明:0 买日平均空仓方向正确(zero_buy 汇总为负,待修 bought 列后重算)、无门影子组 −4.65% 远差于真实 −0.30%、放行的 2 笔买单还亏了 3.4%。**当前被证明的能力是"避坑"(veto edge +4.35pp),从未被证明的能力是"抓肉"(buy edge n=2 全败)。** 所以"让每天多出几张买单"本身不该是目标——**让买单的产生和验证机制在 T+2 尺上闭环起来**才是。

但链路确实有三个结构性不一致,它们共同决定了"几乎不出买单、偶尔出还不赚":

### 病灶一:07-10 换了尺子,语义层还穿着 swing 的旧衣服

fwd_2_oc 主尺已经贯通了**度量**(账本/校准/回测),但**判断语义**没跟上:

- L3 conviction 的含义还是"这是不是好股票"——L3.5 回测已裁定其中间档在 T+2 上是噪声("为 swing 校准的残留"),只有 ≥70 有 edge;
- L4 的 P2 价值核/三门语义是持仓数周的质检问题。**文献 A13(学术+实务共识):基本面/质量因子在 <1 月尺度基本无截面 alpha,预测力在年级 horizon**——CFO/PE/质押门在 T+2 的正确定位是**尾部风险过滤器**(避免 −5% 以下左尾),不是收益来源;
- 目标价还在给 swing 空间:中位目标 +8% vs 中位 MFE +4%、触达率 43%(且这是 10 日窗的成绩,2 日窗更兜不住);
- 整条链没有任何一层在回答 T+2 唯一要紧的问题:**"明天、后天,谁来买它?"**(兑现机制)。

### 病灶二:各层目标函数局部合理、联合错配,交集天然趋近空集

L1 召回"今天因子面好看的"(9 组截面因子)→ L2 给"多样性菜单"→ L3 选"经得起研究的好股票 + 健康上涨配额"→ L4 要求"主力真在 ∧ 业绩真兑现 ∧ 估值不透支"。每层各自有据,但**没有一层对"下一层的通过率×最终 T+2 收益"负责**。三门要求的画像(便宜+有钱+质量同时成立)在 A 股结构上就稀缺——**0 买是这个 AND 结构在弱市里的数学必然,不是市场没机会**(07-01/03 上涨日照样 0 买是直接证据)。另外系统只有宽基口径的 regime(breadth+pct60),**没有短线情绪相位**(涨停/连板/炸板结构)——冰点该 0 买,修复/发酵段还按冰点的菜单和预算跑,就是把正确纪律外推成了失明。还有一个自增强小回路:**0 买连败旗 → L4 预算压缩(22→15) → 卡更少 → 更难出买单 → 连败继续**——预算旗把"过去没买"变成"将来更难买"。

### 病灶三:反馈饥饿+仪器坏账,买侧永远攒不出可裁决的数据

0 买 → 买侧无标签 → 三门永远无法被前向数据证伪或证实 → 永久 0 买均衡的风险。而且现有仪器不支撑裁决:三门击杀无账本、attribution 缺 bought 列、shadow_buys(conviction top-3 反事实)只回填了 ~30 行且不在报告一等席位、proposals 积压 5 条 open 无裁决节奏。**这条链现在"能学到别买什么,学不到该买什么"。**

### 三个方案(择向点 1,全文最重要的分叉)

- **方案 A · 绝对门槛制(现状延续+仪表完善)**:接受"完美风暴探测器"定位,0 买是常态,主要入口转向观察单触发直通车;只修仪器不动结构。诚实但保守:买侧数据继续饥饿,用户的核心不满(几乎没有 buy)不会缓解。
- **方案 B · 状态机参与制(推荐主体)**:落地已设计未建的 **S1 情绪温度计**(涨停家数/连板高度/晋级率/炸板率/昨涨停今溢价,五相位:冰点/修复/发酵/高潮/退潮,纯确定性零 token)——**相位切菜单和预算,不松门**:冰点=哨兵/极小预算(现状),修复/发酵=启用超跌反弹与接力品相入池、预算旗里的"0买连败"项换成相位项;高潮/退潮=收紧追高品相。门原样,参与度状态化。
- **方案 C · 相对制+仓位(只上纸面)**:每天强制"若必须买 3 只"(shadow_buys 已有雏形),配 S3 sizer(分数 Kelly×vol target×流动性 cap)记**纸面账本**,与真实账本、市场基线三线日日对照。**不动真金**——它是三门的反事实证伪器:若纸面组连续 30-60 日跑赢市场而真实组空转,才有资格谈门的松紧;若纸面组也亏(像那 2 笔 OW),门被加冕,争论终结。
- **推荐:B + C(纸面),A 的仪表修复打底。** 这条路线不违反任何历史裁决("切菜单不放宽门"是 S1 设计原话),又直接回应"几乎没有 buy":修复/发酵段供给会真实变多,买侧证据开始积累。

## 3. 第②问 · 粗排:L2 的正确进化是"更聪明的菜单",不是找 alpha

L2 不上模型已被四年回测+全 zoo 负 IC 裁死,不重启。但"菜单"本身有四个可优化点:

1. **桶结构随相位切换**(S1 消费端,设计稿原文"切菜单不放宽门"):七个风格桶的 floor 现在是死的(趋势20/健康15/反转12/…)。冰点/修复 → 超跌反转桶扩容;发酵 → 趋势/突破桶扩容;高潮/退潮 → 追高品相收紧。落点在 `menu.py`/`l2_stratify`,确定性零 token。
2. **桶内排序的反事实体检**:桶内 merit 排序用的还是 composite(unique 贡献 +0.58%,中游)。影子漏斗基建现成——**加一个 `random_in_bucket` 影子变体**,若桶内随机与 composite 排序的 L2 outcome 无显著差,说明排序在浪费信息密度,应换成"各桶用各自 lane 的原生信号排序"(动量桶用动量分、反转桶用反转确认分)——这比全局 composite 更贴桶语义,且免费可证。
3. **表列面向 T+2 换血**(与 L3 输入联动,见 §4):22 列里 roe/np_yoy 是年尺度慢变量(A13),但 L3 rubric ③仍需要——保留;**增补 2-3 个短尺列**:隔夜跳空史(A2/A3)、近 5 日炸板/涨停旗(A6)、turnover 分位(A12 彩票效应的条件变量)。列预算不变的话,可挤掉 gbdt_score(与 composite 高冗余)。
4. **menu_health 从读数升级为再分配器**:落刀 >60% 现在只缩 L4 预算——可以同时在 L2 端把落刀品相桶 floor 临时减半(确定性规则,parity 开关)。菜单病该在配菜时治,不是只在点菜时少点。

## 4. 第③问 · 精排 L3:context/prompt 的病根是"注意力超载+确信度失义"

**病象回放**:误读自见数据 22/31;conviction 中间带 87% 早停、T+2 上是噪声;trend lane 高确信被 L4 翻案 33%;近四跑 conviction≥70 塌缩到 0。**这是注意力问题+校准问题,不是知识问题**——200 行×22 列≈4400 个裸浮点一次通看,文献 B3(lost in the middle,共识级)和 B8(位置偏差)预言的正是这种系统性略读。

按"越便宜越先做"排序:

1. **行级语义指纹(确定性预计算)**:每行预生成一个画像短语列,如 `低位放量突破·主力+·PE中·两板史`——LLM 读词远比读浮点稳。misread 三谓词(低基/背离/套牢)已经是这个思路的雏形,推广成全行指纹。成本 XS,直接打误读。
2. **thesis 数字机检回环**:L3 写完 judged.json 后,确定性 lint 把 thesis 里引用的数字 parse 回表核对,不匹配 → 打回自修一次(仅一轮,防循环)。22/31 病的末端闸,成本 S。
3. **顺序去偏**:表按 lane 分块呈现(块内按 in-lane 信号排序,记录 seed)——lane 内相对比较比全局 composite 序更贴"比较式精排"的本意,也避免 composite 的视角垄断表序;既有的周检 shuffle 审计升级为**双序跑取交集**(仅周检做,成本可控;B8 的标准缓解)。
4. **conviction 操作性重锚(T+2 语义)**:prompt 里把档位定义改成行为语言——"**≥70 = 我能说出 D+1 谁来买、且愿意明天开盘真金买入**;50-69 = 值得 L4 验但我不背书;<50 不该出现在 finalist"。配合每日 ≥70 限额(~5 只)防通胀。L3.5 回测(只 ≥70 有 edge)是这个重锚的依据;重锚后 L3.5 的 conviction_floor_quota 闸值得半年后重测。
5. **新 rubric 维⑥:T+2 兑现机制**:每条 thesis 强制写"两日内的兑现机制"(催化落地/突破跟随/板块轮动位/超跌第一波修复)+"明日买家是谁"。这是把 fwd_2 标签写进选择准则的最直接方式,也是全链目标函数对齐(病灶二)在 L3 的落点。
6. **per-lane 翻案基率注入**:硬约束 D 现在手写死"trend 33%(n=52)"——改由 cross_calib 动态生成 lane×conviction 档的翻案率表注入(n<10 档标⚠禁注,沿用惯例)。X1 的 L3 版,数据现成。
7. **两遍法(备选,若 1-3 落地后误读仍 >15%)**:pass1 机械分诊 200→60(每 lane 前 N+多路共振+相位对口品相,近乎确定性),pass2 对 60 只恢复 42 列宽表深比较。同 token 预算下单行注意力×3,但多一次派发、慢 ~5 分钟——所以排在便宜三件之后。

**不动的**:市场研判防锚定铁律(§1-3 描述性喂 L3)、硬约束 A/B/C(用户拍板)、E 误读自证——文献 B1/B6 全部站在这些设计一边。

## 5. 第④问 · L4:单票研究 agent 的"全面准确"=先防污染,再补基率,最后对齐超短

现有 P0-P5 渐进深度+早停+rubric 派生评级的骨架,文献几乎逐条背书(B7 推理先行/B8 逐项评分/B9 硬门槛对抗中枢化)。要动的是四类:

### 5.1 防污染(输入侧,B1/B2 直指现状的一个真风险)

简报现在带 L3 的 conviction 和方向性 thesis。**B2(单一 benchmark 但方向明确):给出前置评级会让从众率 89.5%→95.9%**;"简报只定向不判"的铁律挡不住锚定效应本身。改法(成本 S,契约微调):

- **盲读微 pass**:P1 先读 slim 数字块,写 3 行独立初判(资金/技术/估值一句话),**然后**才读 L3 论点做裁决表。第一口是数据不是论点。
- 简报里 L3 的 thesis 改写成**中性前提清单**("前提 1:主力 5 日净流入为正"),不带"L3 认为值得买"式措辞;conviction 数字保留(误杀保险需要它),但挪到裁决表之后出现。

### 5.2 补基率(B4/B10:自报置信度不可当概率用,频率证据优先)

- 卡头注入 3 行频率锚(cross_calib/buy_ledger 现成):"同 lane 高确信历史翻案率 X%(n)""过三门票 T+2 胜率 Y%(n)""该评级档历史 T+2 均值 Z%(n)";n<10 标⚠。
- **目标价锚 hi_2_oc 分布**:目标 = min(自估, 该 lane×regime 的 hi_2 历史 p60),卡上印"历史同类触达率"。直接治 43% 触达/目标 2× 过乐观。
- 机器块字段序:rating/conviction 排最后(B14,evidence-before-verdict 的字段级执行);parse_rating 兼容改。

### 5.3 语义超短化(A13/A15/A6,门不松,记账和分级变)

- **三门记账口径改"左尾避免"**:先建三门结构化账本(现在没有!),KPI = 被门拦下的票后 2 日落入 −5% 左尾的比例 vs 放行组——A13 说这才是质量门在 T+2 的正确考核;别再用"平均超额"考它,考不出来还引发松门冲动。
- **雷分级**:2 日内可引爆(监管立案/解禁日/减持公告/质押平仓线/**当日炸板** A6)保 binding tripwire;慢雷(商誉/长期质押比例)降 advisory 注记。动前先看新账本 20 日。
- **制度块**(A15):卡加两行——"隔夜跳空预算"(T+1 制买入日无法止损,最大可承受 gap)与"可成交性"(一字板/流动性)。与 S4 保真度(涨停不可成交)同一世界观,卡端先行。
- 新闻段维持"事件行+净分"压缩(B13:换成情感分不掉性能省 token;长原文只给 survivor P4)。

### 5.4 买单的独立复核(择向点 2,历史敏感)

买单 skeptic 已被用户裁撤,不提议复活常设岗。但 B5/B10(学术):**同 agent 自查最不可靠,独立 run 集成+取中位是已收敛的最优配方**。折中形态:**仅对 ≥OW 候选**(日均 0-3 只)并发 2-3 个独立 l4-card(乱序输入/不同 seed),**取中位评级**;分歧 ≥2 档才升 L5 人裁。成本可控(只 survivor),且形态是"集成"不是"抬杠"。买侧 2 笔全败的现状值得给最后一道便宜保险。
