# 衍生品领先性普查(2026-08-24)

## 0. 假设与判读规则(先写后看;本节 commit 早于任何读数)

**问题**:T 日收盘后可知的衍生品市场信号——QVIX(波动率指数)、期权 PCR(持仓/对冲压力)、股指期货年化基差、期权/期货到期日历——对 **T+1 之后的市场级结果**,有没有超出 breadth + 动量基线的领先性?

**为什么现在问**:`autoresearch/derivatives/`(options_lake / qvix / style_spread / cb_gate,2026-08-04 建成)至今**零生产调用方、磁盘零数据**;08-03 设计稿 §2.2 写明的「最小证伪步」**从未执行**。同时 2026-08-24 探针证明 `opt_daily` 与 QVIX 都有可回补的历史 → 证伪不需要等日积月累,一次回补即可出全读数。本普查把四族信号放进同一张表、同一把尺、同一个基线,一次看完。

- **H0**:四族没有任何一个信号过下述「正证据」线(08-03 稿的谨慎默认:期权只配当地形展示,不配进判断)。
- **H1**:至少一族过线。
- 本普查**不裁决任何接线/哨兵/日历变更**,只给裁决者看读数。

**PCR 语义**(随每个读数一起走):PCR = 对冲/持仓压力,**不是方向观点**——它无法区分买 put(看空)与卖 put(看多)。任何把 PCR 直接标成「看空」的渲染都是错的。**分品种,永不合并**:不同 ETF/指数的合约乘数与参与者结构不同,裸加总没有意义。

### 0.2 因变量(把证伪尺对齐到产品真做的事)

信号在 T 盘后可知 → 若被 E6/scan 消费,影响的是 T 晚决策、T+1 收盘买、T+2 开盘卖的持仓。故:

- **主判读 target**:`gap` = 该信号自己标的指数的 close(T+1) → open(T+2) 收益(与产品主尺 `gap_c1_o2` 完全同窗,2026-07-10 / 08-05 用户裁定);
- **观察 target(只印不判)**:`oc_t1` = open(T+1)→close(T+1)(若日内可行动)、`d_breadth_t1` = breadth(T+1) − breadth(T);
- **公共观察列**:000300.SH 与 000852.SH 两个基准的 `gap`(族间可比);
- **A2 哨兵专测尾部**:H 档(急升)之后 P(标的指数 close-to-close(T+1) ≤ **−1.5%**) 相对无条件基率的**提升倍数** —— 哨兵要的是尾部预警,不是均值。

### 0.3 判读规则

- **档位**:signal_T 在滚动 250 日窗内分位 ≤ **20%** = L 档、≥ **80%** = H 档、其余 M(walk-forward:切点只用 ≤T 的数据,无全样本前视);
- **正证据**(逐信号 × 主 target,三条**同时**成立):
  1. H−L 条件均值差方向明确 ∧ Newey-West t(lag=5)|t| ≥ **2.0**;
  2. 两档各 n ≥ **100**(D 族:旗日 vs 非旗日 two-sample,旗日 n ≥ **20**);
  3. **基线增量成立**:OLS `target ~ signal_z + breadth_T + idx_mom20_T` 中 signal 的 NW-t |t| ≥ 2.0 **且与 H−L 同号**(同期相关、被 breadth/动量解释掉的都不算);
- **显著负**:H−L 与「若它是有用信号该有的方向」相反 ∧ 上述 1、2、3 同时成立;
- **未证**:其余(**不显著 ≠ 有 alpha**);
- **样本不足**:任一档 n 低于门槛(只印数,不判);
- **A2 尾部**:提升倍数 + Fisher 精确 p,`p < 0.05` 才算过;
- **不设停机**——普查不是门。**全表印出**:判读只认预注册主列(信号自标的 `gap`),其余为观察列;正证据数必须与「总共测了多少格」一起报,防多重比较错觉。

### 0.4 口径

- **主判读窗 = 2022-03-02 起**(`lake/daily` 起点;breadth 基线可得、IM 在窗内)。2016 起的长史只出 raw H−L **观察列,不判读** —— 缺 breadth 基线,窗混着判会造成族间不可比;
- `breadth_T` = 当日全湖可交易票中 `pct_chg > 0` 的占比(`lake/daily` 直算);`idx_mom20_T` = 对应指数 20 日收益;
- **QVIX 有效起点** = 首个连续 ≥ **60** 交易日全非空段的起点,之前全弃(接口谎报起点,见 §0.5);死序列(末行关键列全 NaN)整条弃并记账;
- **指数 target 极值**:`|gap| > 8%` 视作数据错,剔除并计数(个股的 31% 板极值阈不适用于指数);
- **缓存缺日**:该信号该日不计,**不伪造为空**;coverage 报每族有效日数;
- **不分 regime**(样本薄,加了只会诱导调参);**不做任何个股级断言**。

### 1.1 唯一的正证据:股指期货年化基差(C2)

### 1.2 三条事后对抗性复核(**不在 §0 预注册内,不改判读**;唯一的正结果该受的检验)

| 复核 | 问的问题 | 结果 |
|---|---|---|
| ① 加「T 日指数自身涨跌」控制项 | 基差是不是只是今天涨跌的替身? | **通过** —— IC t 2.31→2.31、IM 2.56→2.54,几乎不动 |
| ② 期货腿改用 `close` 而非 `settle` | `settle` 是当日加权均价,会不会把尾盘路径混进来? | **不通过** —— IC H−L 减半(+0.192→+0.131pp)、基线增量 t 2.31→**1.57**;IM H−L t 3.10→**1.92**。两格在 close 口径下**都不再是正证据** |
| ③ 判读窗对半分 | 是不是只靠某一段行情? | **半通过** —— 四品种两半同号,但强度集中在前半:IC t 前半 +3.00 / 后半 **+0.57**;IM +2.27 / +1.26 |

**读法**:按 §0.3 预注册的三条判据,C2 有正证据;但它对**期货价格口径**(settle vs close)与**样本时段**都不稳健。这不是「结论被推翻」,是「结论的适用范围比表面窄」—— 任何据此的接线提案都必须先解决口径依赖(为什么 settle 有而 close 没有)与近两年衰减。

### 1.3 三族的干净负结果

- **A·QVIX(18 格,0 正证据)**。水平分位、单日急升、VRP 三个假设全部未证;族内最大 |t| = 1.22。最有力的一格是长史观察列:`qvix_pctile[50etf]` 自 **2015-02-09** 起 1,293 个档位日,H−L = **+0.002pp,t=+0.05** —— 十一年半的样本上,50ETF 波指的高低档对次日隔夜**没有任何可测差异**。
- **A2 哨兵(族E)不被支持**。尾部专测:六条序列的急升日之后,标的次日收收 ≤ −1.5% 的条件概率相对基率提升 0.83×~1.27×,**没有一条 Fisher p < 0.05**(最接近的是创业板 1.27×、p=0.071)。哨兵立项的前提不成立。
- **B·PCR(36 格,0 正证据)**。12 个品种 × 3 个口径(成交量 PCR / 持仓 PCR / ΔPCR)全部未证,族内最大 |t| = 1.66。
- **D·到期日历(6 格,0 正证据)**。到期日 / 到期周 / 到期次日三旗 × 两基准全部未证;最强的 `post_expiry` +0.088pp、t=+1.10。

### 1.4 数据体检(仪器自证)

- **QVIX 有效起点验定成功**:六条序列还原出的起点 —— 50ETF **2015-02-09**、300ETF **2019-12-23**、500ETF/创业板 **2022-09-19**、深100 **2022-12-12**、科创50 **2023-06-05** —— **全部精确等于对应期权的真实上市日**。接口自报的「八条序列都从 2015-02-09 起、2796 行」是回填假象(§0.5)。
- **PCR 覆盖 1,366 日,元数据缺失合约 0 个**(强制分页 + as-of 联结对平)。12 个品种全部通过 500 日数据质量门,无品种被挡。
- **丢弃合成连续合约 59,786 行**:`fut_daily` 里的 `IF.CFX`/`IFL1.CFX` 这类行的 `oi` 是整族加总 —— 不滤掉,「当日最大 OI = 主力」会**永远**选中合成行,而基差照样算得出一个看起来正常的数。
- 到期日 216 个(判读窗内到期日 107 天、到期周 409 天);指数 target 极值剔除 18 格次(每指数 2~3 次);breadth 1,087 日。

### 1.5 相对 §0 的偏离与澄清(逐条)

1. **「显著负」不适用**:信号符号可自由翻转(预测跌与预测涨同样是信息),故判读只分「有没有领先性」。三条判据一字未动。
2. **回补窗 2021-01-04 而非 2016**:实测 `opt_daily` 0.82 s/call,2016 起全史需 ~3.5 小时。判读窗(2022-03-02)只需 250 日暖机,故回补自 2021-01。影响:B/C2 的长史观察列被截到 2021-01(A/D 不受影响,它们的长史来自 QVIX 与 `opt_basic`,均已全史)。
3. **QVIX「有效」定义含 `>0`**:1000 指数序列里夹着 34 个 0,**0 不是波动率**。§0.4 只写了「非空」,此处按「非空 ∧ >0」执行并在此声明。
4. **两条指数 QVIX 按 §0.4 整条弃**(300index/1000index 末行关键列全 NaN),中证1000 的暴露由 C2 的 IM 基差承接 —— 事后看,被弃的那条序列所对应的品种恰恰是唯一出正证据的地方。
5. **FDR q 是补充列**,不参与判读,用于对照「正证据 2 格 vs 可判 57 格」。
